Fleet tile studies

Five ways to draw the Fleet tiles, all showing the same sample devices. The data below is made up for comparison. Pick a letter and it can go into the Fleet page.

ADetails card BPump forecourt CHealth ring DStatus wall ESignal strip

ADetails card

The current tile, tidied: status in the header, a fixed key/value list, actions in the footer. Offline devices get a red top edge. Good all-rounder, about 4 per row.

BPump forecourt

Built around the two nozzles: each shows its pump ID, live state and the last sale in litres. A fuelling nozzle turns green with a moving flow bar. Best when the question is "is this pump working right now?".

CHealth ring

A 0–100 health score in a ring (seen recently, DT answering, FW current, SD card, Wi-Fi, open issues), the checks that failed as pills, and a 24-hour message sparkline. Best for spotting devices that need attention.

DStatus wall

Small tiles grouped by shed, many per row: name, pump IDs and last seen, with the colour edge for status and an amber outline when something needs attention. Built for the whole fleet on one screen; details open on click.

ESignal strip

A wide row per device: a status block on the left, one line of site details, then icon readings (Wi-Fi bars, SD free, DT version, probe time) and the firmware with an "update" flag on the right. Reads like a list but keeps the tile grid.
