## Project Overview
- Embedded firmware message library for FERP/HSYS devices (ESP32-based)
- Workspace: `/Volumes/DataMac/SAS/ferp-message-library`

## Key Directories
- `src/app-messages/` — message codec and message types
- `src/app-modules/` — application modules (HTTP, MQTT, OTA, WiFi, printing, etc.)
- `src/sub-modules/` — drivers, framework, OS, middleware, PAL, utils
- `tools/ferp-device-tool/` — Python-based device management tool
- `releases/` — firmware bundle releases
